# Contributing

Two kinds of issues are welcome.

**A template that fooled SniffBot.** Open an issue titled "Missed: [template name]". Include the x.ai/bot link, what SniffBot said, and what it should have caught. If the template has since been removed, paste a redacted copy of the text instead.

**A rule that should exist.** Open an issue titled "Rule: [short name]". Say what the rule catches, give one real or realistic example, and link a source if you have one (a security writeup, a docs page, a post).

Pull requests that edit SNIFFBOT.md are welcome too. Keep the voice: plain, humble, no technical words without a plain explanation, no emojis, no dashes. Do not add plugins, routines, or memory writes. SniffBot's restraint is the point.

Kacper reviews everything before it goes into the live template. Changes ship in numbered versions (see CHANGELOG.md).
